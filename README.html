LunAlpha HUD - Command Manual

Welcome to the LunAlpha HUD manual. All commands are executed via the standard in-game chat. Note that commands starting with ! are silent and will not be seen by other players unless specified.

Host Requirement: Commands that affect other players (like Kick, Ban, Arrest, Spawn) require you to be the Host of the lobby.

Network & Players

!list
Aliases: !peers, !players

Prints a local list of all active remote players and their Peer IDs. Use these IDs for targeted commands.

!info <id>

Performs a deep scan of a specific player and prints the results locally in your chat. Displays their equipped Perk Deck, total Skill Points, Accuracy stats, and any synchronized SuperBLT mods. Ignores empty or hidden data to keep your chat clean.

!debug <id>

Similar to !info, but focused on technical data. Highlights illegal skill point totals (over 120 pts) and displays their current SuperBLT version.

!mods <id>
Aliases: !m

Prints a list of the specified player's synchronized mods in your local chat.

Security & Moderation (Host Only)

!kickcheck
Aliases: !cheaters

Automatically scans the lobby for players using blacklisted mods, DLC unlockers, aimbots, or illegitimate skill points. Will automatically kick flagged users.

!ssl

Executes a Deep Integrity Scan. Runs the kickcheck algorithm AND automatically generates a lobby snapshot log file (see File Locations).

!kick <id>
Aliases: !k

Instantly kicks the specified player from the lobby.

!ban <id>
Aliases: !b

Kicks the player, adds them to the internal Luna Blacklist, and automatically syncs them to the Vanilla Payday 2 banlist. Stores their Steam/Epic profile URL.

!unban <id>

Removes a player from both the Luna Blacklist and the Vanilla banlist.
Tip: Typing !unban without an ID will automatically unban the last person you banned.

!arrest <id>
Aliases: !jail, !mute

Places the targeted player in handcuffs indefinitely. Useful for stopping griefers mid-heist without fully kicking them.

Tools & Navigation

!leave

Instantly aborts the current heist and returns you directly to the Main Menu. No confirmation screens.

!quit
Aliases: !q, !exit

Forcefully closes Payday 2 and returns to your desktop.

!log

Takes a comprehensive snapshot of the current lobby (Platform info, FBI URLs, Builds, Accuracy, Mods) and saves it as a permanent .log file on your computer.

!readyup

Locally identifies which players have not pressed "Ready" in the pre-planning screen, and publicly reminds them in the chat.

!spawn
Aliases: !s, !load, !unstuck

Forces the game to spawn all players currently stuck in the "waiting to join" phase. (Host only).

!stats

Toggles the Quake-style Combat Stats Feed (Kills, Specials, Accuracy) on or off.

!version

A public "handshake" command. When typed, any other LunAlpha HUD users in the lobby will automatically reply with their current version.

File Locations & Logs

LunAlpha HUD operates locally on your machine and generates evidence files for security purposes. Here is where you can find your data:

Lobby Snapshots (Logs)

When you run !log or !ssl, the HUD generates a detailed text file of the lobby. This is useful for reporting cheaters to server admins.

PAYDAY 2\mods\LunAlpha_MinimalHUD\logs\

Files are named LunaLog_YYYY-MM-DD.log

The Blacklist Database

When you use !ban, or when the auto-kicker catches a cheater, they are saved to a local JSON file. This file contains their name, platform URL, and the reason for the ban.

PAYDAY 2\mods\LunAlpha_MinimalHUD\luna_blacklist.json
HUD Settings

Your toggles (Quiet Mode, Buffs, Stats, Crosshair) are saved in the standard SuperBLT save directory.

PAYDAY 2\mods\saves\lunahud_settings.json
