# LunAlpha HUD (LunaHUD)
**Minimalism. Precision. Stability.**

LunaHUD is a lightweight interface overhaul for Payday 2, designed by S.G.Johansson. It is built to remove visual clutter while providing critical tactical data and lobby security.

## Project Vision
* **Performance First**: Zero impact on frame rates through optimized Lua logic.
* **Clean UI**: A focused HUD that highlights what matters during combat.
* **Integrity**: Built-in tools to monitor lobby health and prevent cheating.

## Current Barebone Features (v1.0.1)
* **Investigator System (V3.0)**: Advanced peer monitoring with automated logging, FBI suspect linking, and accuracy tracking.
* **Modular Core**: Clean initialization and global table management for stability.
